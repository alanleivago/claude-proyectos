**Character animation by code (and its limits)**
- [02:33] Chat step: "Move the characters with code: arms, breathing, the head".
- [02:34–02:35] Claude's script `before_anim.py`, in a VS Code project named PEOPLE-MOTION (files: .venv, before_anim.py, README.md, requirements.txt). Readable content:
  - `def rot_world(bone, axis, ang)`: rotates a pose bone around its head.
  - `def aim(bone, d)`: points a bone along a direction.
  - `def seg(f, a, b)`: smoothstep ease, `x*x*(3-2*x)` on a clamped 0–1 ramp.
  - `BUTTON = Vector((-0.22, -0.58, 1.12))`: the target for the button press.
  - `keys = body.data.shape_keys.key_blocks`
  - `SURPRISE = {"browinnerup":1.0, "browouterupleft":0.9, "browouterupright":0.9, "eyewideleft":0.85, "eyewideright":0.85, "jawopen":0.42, "mouthfunnel":0.25}`: these are ARKit-style blendshape names.
  - `b.rotation_mode = "QUATERNION"`, a per-frame loop `for f in range(NF)`, and `b.matrix_basis = REST[b.name].copy()`.
  - Relaxed arms per side "L"/"R": `aim("upperarm01.{s}", Vector((0.13*sx, 0.02, -1)))`, plus `lowerarm01`.
  - Finger loop `for fi in range(1,6)` and `for j in (1,2,3)` over bones named `finger{fi}-{j}.{s}`.
  - Breathing: `rot_world("spine02", Vector((1,0,0)), math.radians(0.6 * math.sin(2 * math…` (about 0.6° sine on the spine).
  - Reach logic: `reach = seg(f, PF-25, PF) * (1 - seg(f, PF+20, PF+45))` (reach in 25 frames, hold, release over 25 frames).
  - The bone names (upperarm01, spine02, fingerN-M) look like a MakeHuman-style rig.
