# trash-library — shot list (beat table v1)

61.0 s, 9:16, 30 fps (1830 frames). Voice: VoiceStudio "3d cartoon" 227af074, take 14, pauses tightened
(56.5 → 55.54 s) + 3 wordless gags (+3.2 s) = 58.74 s; closing gag 58.40–61.00.

**Camera (new rule 2026-11-11):** each set is ONE continuous take; the camera travels a spline through the set
(push → whip to the next subject on its word → orbit with parallax → crane → dutch roll in/out), changing axis every
1.2–1.8 s, never stopping. Set changes = whip with motion blur in the travel direction. 5 takes = 4 whips.

## Sets
- **A street** — Ankara at dawn: low apartment blocks with balconies, a mosque dome + minaret far back, Turkish flag,
  simit cart, orange municipal garbage truck "ÇANKAYA", bins, bags on the sidewalk, pink-orange sky.
- **B depot** — sanitation depot break room: lockers, tea urn + tulip glasses, notice board, table, window to the trucks.
- **C factory** — the old brick factory turned library: brick vaults, a kiln chimney, tall shelves, reading tables,
  kids' corner with rug and beanbags, desk with a book counter sign.
- **D lending** — the library's loading bay + three tiny vignettes (village school, prison cell) via a crate-label whip.
- **A' street** again for the ending (same set as A, now daytime).

## Facts on screen (checked 2026-11-11)
- Çankaya (Ankara) sanitation workers, library in an old brick factory, opened 2017; first for workers & families;
  lends to schools, village teachers, prisons — Smithsonian, Mental Floss (2018).
- ~6,000 books the first year; 25,000+ (2019–2023 coverage); one source 40,000+ — Matador Network, Good Good Good.
